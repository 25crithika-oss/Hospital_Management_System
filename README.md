# Hospital Management System

A web-based Hospital Management System developed using Python Flask and SQLite. This system helps manage patients, doctors, appointments, and billing records through a simple and user-friendly dashboard.

## Features

- Patient Registration and Management
- Doctor Management
- Appointment Booking
- Billing and Payment Management
- Patient and Doctor Search
- Dashboard with Dynamic Statistics
- SQLite Database Integration
- Responsive User Interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
